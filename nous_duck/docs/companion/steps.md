# 鴨子夥伴功能：分步進度

最後更新：2026-11-25 22:40（整合線）。設計見 [總體設計](README.md)。

怎麼讀：

- **狀態**：`完成`／`進行中`／`未開始`／`卡硬體`（程式做到能做的程度，等硬體）／`等你`（要使用者決定或在場）。
- **驗證層級**：`單元測試`、`模擬`、`實機`（寫明動了什麼）。沒有寫「實機」的，就是還沒在真的鴨子上驗證過。
- 各線的細節（做了什麼、怎麼執行、測試結果）在各自的進度檔；這一頁是總表，由整合線在各線回報後更新。**各線分支還沒合進整合分支之前，這一頁寫的是該線自己回報、整合線查核過的狀態**，連結的檔案在那條線的分支上。
