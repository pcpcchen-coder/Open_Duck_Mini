# 鴨子夥伴功能：分步進度

最後更新：2026-11-26 07:00（整合線）。A～D 四條線已**合併進整合分支** `claude/duck-companion-overnight` 並推送；下一批「桌上互動」見本頁最後一節。先看 [晨間報告](morning-report-2026-11-26.md)。

怎麼讀：

- **狀態**：`完成`／`進行中`／`未開始`／`卡硬體`（程式做到能做的程度，等硬體）／`等你`（要使用者決定或在場）。
- **驗證層級**：`單元測試`、`模擬`、`實機`（寫明動了什麼）。沒有寫「實機」的，就是還沒在真的鴨子上驗證過。
- 各線的細節（做了什麼、怎麼執行、測試結果）在各自的進度檔；這一頁是總表，由整合線在各線回報後更新。2026-11-26 起各線已合併，連結的檔案都在整合分支上。
