# R-003：快沒電時要求回家充電

- 提出：使用者，2026-11-26
- 狀態：**需求已記錄；設計為草案**（[ADR-0009](../adr/ADR-0009-low-battery-return-interaction.md)）。尚無程式、尚無硬體驗證
- 相關：[R-001](R-001-mobile-companion.md) S4（電量低或任務結束時自己回充電座）、[ADR-0004](../adr/ADR-0004-docking-and-charging.md)（充電座與回充流程）

## 1. 使用者原始需求

> 這個對話處理鴨子快沒電時會要求回家充電的事件，請幫我設計互動，以及在哪種條件下，會直接回家充電。

拆開來是兩件事：

| 要設計的 | 內容 |
|---|---|
| 互動 | 鴨子快沒電時，怎麼、什麼時候跟使用者說要回家；使用者可以怎麼回答 |
| 直接回家的條件 | 哪些情況鴨子不問、自己回家；哪些情況就算沒電也不能自己走 |

## 2. 驗收情境（草案）

| 編號 | 情境 | 期望 |
|---|---|---|
| B1 | 鴨子在客廳陪使用者聊天，電量逐漸下降 | 先在對話空檔提醒一次；之後請求回家並給選擇；使用者說「好」就回家；到家以電氣訊號確認充電後才說「開始充電」 |
| B2 | 使用者說「再等一下」 | 延後一次，告訴使用者最多再幾分鐘；到時間或電量更低就回家 |
| B3 | 電量已到底線，使用者說「不要回家」 | 鴨子說明原因後仍然回家；使用者說「停」就停下，改成請人抱回充電座 |
| B4 | 鴨子正在去 `brother_room` 的路上電量到底線 | 取消任務、回家，Nous 告訴下任務的人任務沒完成 |
| B5 | 實體隱私開關關閉、太暗、或迷路時快沒電 | 不盲走；停在原地，說出所在地點，請人抱回充電座 |
| B6 | 電量低到走不回家 | 不硬走；求救；最後安全停機，不摔壞鏡頭 |
| B7 | 和 Nous 的連線斷了 | 到底線時仍自己回家（用機上預錄語音說一句） |

情境裡的數字（門檻、等待秒數）見 ADR-0009 §3、§4，全是草案，要量測耗電後才定。
