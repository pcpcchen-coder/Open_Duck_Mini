# R-001：行動夥伴需求（導航、行動對話、喚醒找人、自動回充）

- 提出：使用者，2026-11-12
- 狀態：**需求已記錄；設計為草案**（[ADR-0002](../adr/ADR-0002-indoor-localization-and-navigation.md)～[ADR-0006](../adr/ADR-0006-privacy-settings.md)）；尚無程式、尚無硬體
- 2026-11-12 使用者決定：雙板（Pi Zero 2 W＋Pi 4）、鏡頭 AR0144 裝在頭上、麥克風 reSpeaker Flex XVF3800 Circular-4 裝在身體上、加實體隱私開關、眼燈顏色提示鏡頭狀態、充電觸點在背後、可以貼 AprilTag、喚醒詞晚點取名、隱私規則可開關並採建議預設值
- 隱私：本 repo 是公開的，文件中的人與房間一律用 ID（例如 `brother`、`brother_room`）。真實姓名與房間對照只存在 Nous 本機設定，不進版控。

## 1. 使用者原始需求（姓名以 ID 代替）

1. 鴨子要有**跟掃地機器人一樣的導航**，要設計怎麼在室內定位。鴨子走路會打滑，**不能用步數推估位置**，要用其他方法。用途是叫鴨子去某個房間做某件事，例如「去哥哥（`brother`）房間叫他起床」。
2. 鴨子有**麥克風、喇叭和雙目視覺**，可以走到任何區域跟使用者對話互動，角色類似目前的 Raspberry Pi 終端。現在的 RPi 是螢幕上的電子腦，透過 eMeet 麥克風和雙目鏡頭在固定區域跟使用者互動。
3. 鴨子支援**新的喚醒詞**，醒來後會**走去找是誰叫醒它**。
4. 鴨子有**家（充電座）**，會像掃地機器人一樣**自己回家**。

## 2. 驗收情境（草案）

這些是之後的驗收目標，**目前都沒有達成**。

| 編號 | 情境 | 通過條件（草案） |
|---|---|---|
| S1 | 使用者在客廳說「鴨子，去哥哥房間叫他起床」 | 鴨子從目前位置走到 `brother_room`，途中不撞上家具或跌倒；房門關著時停在門口並回報；找到人後用語音叫醒；依對方回應或逾時回報結果；最後回充電座 |
| S2 | 鴨子在廚房，使用者走過去跟它說話 | 鴨子用自己的麥克風聽、喇叭回答，對話品質不低於 RPi 終端（指標待定） |
| S3 | 使用者在另一個房間喊鴨子的喚醒詞 | 鴨子回應（聲音）、判斷方向或房間、走過去、用臉或聲音確認是誰、開始對話；找不到就誠實回報 |
| S4 | 電量低或任務結束 | 鴨子自己走回充電座、對準、確認開始充電；失敗會重試並回報 |
| S5 | 任何時候 Wi-Fi 斷線 | 鴨子停下站好，不掉下樓梯、不亂走；恢復後回報，不自動繼續斷線前的動作 |

## 3. 隱含需求（設計時發現的）

- 鴨子要**認得房間**：需要一份室內地圖，房間與地點有 ID 與本機顯示名稱。
- 長時間任務：走到另一個房間要幾十秒到幾分鐘（上游手把設定的最高前進速度是 0.15 m/s），超過 AIOS 工具單次 60 秒的時限，需要非同步任務模式（見 [ADR-0001 修訂](../adr/ADR-0001-duck-role-in-nous.md#7-2026-11-12-修訂行動夥伴)）。
- 樓梯、門檻、厚地毯、關著的門：鴨子不能開門也不能爬樓梯，地圖要能標禁區與不可通行處。
- 跌倒後鴨子**不能自己站起來**（上游 v2 沒有起身動作），只能回報求助。
- 臥室裡的鏡頭與麥克風：需要隱私規則（見 [ADR-0003 §6](../adr/ADR-0003-mobile-terminal-wake-and-find.md#6-隱私)）。
- 加裝感測器與運算板會改變重量與重心，**上游步態策略可能要重新訓練**（見 [ADR-0005](../adr/ADR-0005-compute-and-sensor-upgrade.md)）。
- Pi Zero 2 W 跑不動雙目定位、喚醒詞、語音串流加步態，需要升級運算（見 ADR-0005）。
