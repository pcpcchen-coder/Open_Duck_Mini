# 舵機設定紀錄（2026-11-21）

14 顆 STS3215 用 [`servo_bench.py wizard`](../../tools/servo_bench.py) 逐顆設定 ID 與零位，**實機完成 14/14**。原始紀錄：[`servo_setup_2026-11-21.json`](servo_setup_2026-11-21.json)。

## 環境

- 舵機板：Waveshare Bus Servo Adapter (A) V1.1，USB 轉序列晶片 CH343（`1a86:55d3`），跳線在 B（USB→SERVO），接 Mac mini。
- 舵機供電 6.9–7.0 V（設定過程中讀到的範圍）。注意板上絲印寫「DC 9~12.6V」，但這批是 7.4 V 版的 C001，**不要接 12 V**；Waveshare 產品頁另註明可輸入 5~8.4 V，且輸出電壓等於輸入。
- 鮑率 1 Mbps；每顆寫入 mode／最大加速度／加速度／P／I／D＝0／0／0／32／0／0，lock＝1，逐項回讀確認。

- 「設定前 ID」等於目標 ID 的 4 顆（11、12、20、31）：第一次嘗試改完 ID 後中斷，重試完成，最後都通過回讀。
- 遇過的問題：
  - 第一次 `setup 10` 寫入時沒等到回應（Mac＋CH343 偶發掉包），工具因此加上讀寫重送 2 次。
  - ID 10 裝舵盤時發現扭力已關（推測中途斷過電），但位置仍是 2050，舵盤對齊不受影響。
- ID 10 另做動作測試：轉到 +0.2 rad（目標 2178，實際 2179）再轉回 2048（實際 2047），電壓維持 7.0 V。
