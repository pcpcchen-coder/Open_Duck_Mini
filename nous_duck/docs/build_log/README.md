從 GitHub 的 HTML 檔案頁下載原始檔，存為 `Open_Duck_Mini_v2_Procurement.html`，再用瀏覽器開啟。清單與計算可離線使用，賣場連結需要網路。可填手上數量、每包數、每包價、已購包數與運費，並匯出 CSV。瀏覽器會嘗試記住編輯進度，請保留 CSV 以便留存。原始碼中的採購預設值是共用清單，個人的勾選和成交價留在瀏覽器。

2026-11-13 的預設預算為 **NT$15,353**，含 26 項原版基本件與耗材，表情套件、額外工具和運費另計。單價欄標示頁面價、缺貨參考價、預算估列或待詢價。頁面價是查價紀錄，結帳價格與可供量依賣家回覆為準。主舵機以機器人王國含稅 NT$651 × 14＝NT$9,114 估算，頁面顯示 1 顆庫存並接受缺貨下單。

電池座、BMS、主電源開關與線材依實際安裝尺寸、DC 電流額定和原版接線圖一起核對。充電板需確認 2S 8.4 V 規格。上游未列完整螺絲或熱熔螺母數量，清單以頁面標註的備料數量先估算。

規格來源：[原版 BOM](https://docs.google.com/spreadsheets/d/1gq4iWWHEJVgAA_eemkTEsshXqrYlFxXAPwO515KpCJc/edit) · [原版組裝指南與接線圖](../../../docs/assembly_guide.md)。各賣場來源列在對應品項旁。
