# ADR-0004：充電座與自動回充

- 狀態：**部分採用**（2026-11-12 使用者決定觸點放**背後**＝方案 B）；其餘仍為草案
- 日期：2026-11-12
- 相關：[R-001](../requirements/R-001-mobile-companion.md)、[ADR-0002](ADR-0002-indoor-localization-and-navigation.md)（導航）、[ADR-0005](ADR-0005-compute-and-sensor-upgrade.md)（硬體）

## 1. 背景

使用者要鴨子有家（充電座），像掃地機器人一樣自己回家充電。原版供電（依上游 BOM）：2S 18650 電池（兩顆約 3000 mAh）、2S BMS、USB-C 充電板、2.1 mm 圓孔接頭、5V 穩壓器、電源開關。原版是**手動接線充電**，沒有自動回充。

掃地機器人回充靠輪子精準倒車與紅外線導引；鴨子是雙足、會晃，停位誤差較大，對準要更寬容。

## 2. 決定（草案）

### 2.1 充電座組成

| 部分 | 內容 |
|---|---|
| 對位標記 | 背板上一張較大的 AprilTag（鏡頭高度附近），提供最後一段的精確相對位姿；地圖上記錄充電座位置（ADR-0002 的 `dock` 地點） |
| 機械導引 | V 形導軌或凹槽，容許數公分的左右誤差與幾度的角度誤差，把鴨子「導」進正確位置 |
| 觸點 | 彈簧觸點（pogo pin）或彈片，在充電座一側；鴨子一側是金屬觸片 |
| 電源 | 充電座只提供直流輸入（規格要符合鴨子上的充電板），**電池的定電流定電壓充電仍由鴨子上的充電板與 BMS 負責**，充電座不直接充電芯 |

### 2.2 觸點裝在哪裡（待決）

| 方案 | 作法 | 優點 | 缺點 |
|---|---|---|---|
| A. 腳底 | 兩隻腳的鞋底各有觸片，走上充電平台就接觸 | 動作最自然（往前走上去） | 改鞋底會影響 TPU 腳底與足底開關、步態；走路時觸片磨地；兩腳的接觸會隨晃動斷續 |
| B. 背後（建議先評估） | 鴨子**倒退**進充電座，觸片在後背外殼 | 觸點不磨地；倒退速度可以很慢；上游步態支援負的前進速度 | 倒退時鏡頭看不到後方，要靠進入前看準標籤再倒退；要改 `body_back` |
| C. 肚子 | 走到位後彎膝蹲低，讓肚子壓到觸點 | 接觸穩定，蹲著時可以省力 | 上游步態策略沒有蹲下動作，要另外做並驗證；要改 `battery_pack_lid` 或 `body_middle_bottom` |

**使用者 2026-11-12 決定採方案 B（背後觸點、倒退進座）。** 因此 `body_back` 要改設計（加觸片與走線），**暫緩列印**，改裝件放 `hardware/dock/`。`battery_pack_lid`、`body_middle_bottom` 不再受觸點影響，但可能要為 Pi 4 改（ADR-0005 §3）；`left_cache`、`right_cache`、`body_front` 等可以先印。

方案 B 的設計重點：

- 倒退時鏡頭看不到充電座，所以要在**面向充電座時**先用標籤算好位姿，轉身 180° 後依 IMU 航向與視覺里程計倒退；最後幾公分靠機械導引收斂。
- 觸片高度與位置要配合 `body_back` 的外形（外框約 40×110×125 mm，從 STL 量的）與站姿高度。
- 倒退速度要很慢，接觸前後都由身體板 safety 限速。

### 2.3 電氣安全

1. **鴨子身上外露的觸片絕對不能帶電**：鴨子一側要有理想二極體或等效保護，電池電壓不能反向出現在觸片上，避免觸片碰到金屬造成短路。
2. **充電座平常不輸出電壓**：偵測到鴨子（例如觸點間的識別電阻或小電流握手）才打開輸出；有限流與保險絲。
3. 低電壓直流，但兒童與寵物可能碰到，觸點要有遮擋或內縮。
4. 充電時監控電池溫度（若加裝感測），過熱停止充電並回報。

## 3. 回充流程

```text
觸發（電量低／任務結束／閒置逾時／使用者說「回家」）
 → 導航到充電座前方約 50 cm 的預備點（ADR-0002）
 → 看到充電座標籤 → 視覺伺服對準：轉向、左右平移（vy）修正
 → 低速進入（方案 B 為倒退）→ 機械導引收斂誤差
 → 確認接觸：偵測到充電輸入電壓或充電板狀態
 → 停止步態、保持站立（方案 C 為蹲下）→ 回報「已回到充電座、開始充電」
 失敗 → 退出、重新對準，最多重試 N 次 → 仍失敗就停在附近回報
```

- 「已充電」的判斷要以**電氣訊號**為準，不是以「走到了」為準。
- 在充電座上時，鴨子可以當固定終端使用（ADR-0003），待機時關鏡頭。
- 離開充電座：先向外走出導引，再開始其他任務。

## 4. 電量判斷

- 上游有 `check_voltage.py`（讀舵機回報的電壓）。電壓在負載下會下垂，只用電壓估電量誤差大。
- 建議加裝電流感測（INA219／INA226 一類）做電量累計（ADR-0005 §2.2，選配）。
- 回充門檻**動態計算**：走回充電座的距離所需電量＋安全餘量，而不是固定百分比；具體數字要先量測走路耗電後才定。
- 電量真的太低、走不回去時：停在安全處、回報位置，不硬走。

## 5. 後果

- 新增 `nous_duck/hardware/dock/`（充電座設計、觸點、電路）。

- 新工具 `app.duck.return_home`；state 新增充電狀態與電量估算。
- 需要量測：走路與待機耗電、續航、充電時間。

## 7. 設計 v0（2026-11-13）

使用者要求設計鴨子的家（充電座）並提到「椅子」。設計 v0 見 [`hardware/dock/`](../../hardware/dock/README.md)，驗證紀錄見 [`validation/dock-cad-2026-11-13.md`](../validation/dock-cad-2026-11-13.md)。重點：

- **外型**：倒退進座＝坐進椅子。屋頂形的高椅背貼 AprilTag（tag36h11 ID 0，黑框 100 mm，中心離地 340 mm），屋頂圓窗是狀態燈；扶手只是外觀與防撞，離鴨子 ≥ 41 mm、不參與導引。
- **機械導引**（§2.1 的 V 形導軌）：鴨子背後的觸點凸台有 45° 導角，充電座的 V 形座與它平行；幾何計算的側向捕捉 ±34 mm、偏航 ±5°。
- **觸點**（§2.1）：鴨子側是兩條直立黃銅片（+y 正、−y 負），充電座側是 4 支彈簧頂針；站高容許 ±30 mm（每極至少一支接觸），V 形座可再上下調 ±15 mm。
- **背殼**：原版 `body_back` 已經印好，改用**外掛觸點板**貼合在原殼上，不用重印；也提供一體式 `body_back_dock.stl`。
- **電氣**（§2.3）：鴨子側二極體擋住反向電壓、識別電阻串二極體（極性錯就看不到）；充電座平常不輸出，偵測到識別電阻才開，有限流與保險絲。
- 驗證層級只有幾何（單元測試）與渲染；**未列印、未實機**。
