# ADR-0006：可開關的隱私設定

- 狀態：**部分採用**：使用者 2026-11-12 要求「隱私規則設計成可以開關設定」，並同意 §5 的建議預設值；實體隱私開關、鏡頭提示方式仍待決
- 日期：2026-11-12
- 相關：[ADR-0003 §6](ADR-0003-mobile-terminal-wake-and-find.md#6-隱私)（隱私原則）、[ADR-0002](ADR-0002-indoor-localization-and-navigation.md)（導航需要鏡頭）、AIOS CLAUDE.md 產品紅線、AIOS ADR-0001（身分不等於授權）

## 1. 背景

鴨子會帶著雙目鏡頭與麥克風陣列在家裡走動，包括進入臥室。不同家人、不同房間、不同時段的期待不一樣，所以隱私規則要能**開關與調整**，而不是寫死。

難處是**隱私開關會影響功能**：鏡頭關掉就不能導航（ADR-0002 靠視覺定位），臉部辨識關掉就只能用聲音找人。設定介面必須讓使用者看到每個開關的代價。

## 2. 決定：兩層規則

### 2.1 固定規則（不能關）

這些是 AIOS 的產品紅線或安全規則，**沒有開關**：

1. 原始影像與未喚醒的音訊**不寫檔、不進 trace、不傳出家裡**。
2. 送到 Mac 的只有特徵（臉部特徵、聲紋特徵）與結果，不送原始影像或錄音。
3. 鏡頭開啟時一定有**看得見的提示**（例如眼燈顏色）。
4. 隱私設定不能讓鴨子做出不安全的動作（例如為了不開鏡頭而盲走）。
5. 公開 repo 不放家人真實姓名與家中資料（根目錄 `CLAUDE.md`）。

### 2.2 可調整的設定

| 層級 | 開關 | 關掉的代價 |
|---|---|---|
| **全域** | 鏡頭 | 不能導航、找人、回充；鴨子只能原地對話或留在充電座 |
| | 常駐喚醒聆聽（麥克風） | 叫不醒鴨子；只能用 Nous 的其他終端或手把下指令 |
| | 臉部辨識 | 找人只靠聲音方向與聲紋，比較容易找錯或找不到 |
| | 聲紋辨認 | 不知道是誰叫的，只能找聲音來源 |
| | 主動找人（被叫醒後走過去） | 被叫醒後只原地回應 |
| | 帶看建圖錄影 | 不能建立或更新地圖 |
| **房間（每個地點）** | 可否進入（永遠／只限指定任務／禁止） | 禁止進入的房間無法在裡面完成任務；鴨子會停在門口回報 |
| | 房間內可否做臉部辨識 | 同上「臉部辨識」 |
| | 房間內可否出聲（說話、叫人） | 不能在該房間叫人或對話 |
| | 時段（例如只限 07:00–08:00） | 時段外視同禁止進入 |
| **家人（每個人）** | 是否參與臉部辨識、聲紋辨認（沿用 AIOS 的主動登記） | 鴨子認不出這個人 |
| | 是否可以被主動找（例如「別來找我」） | 對這個人的找人任務會被拒絕 |
| **模式（一鍵切換的組合）** | 見 §2.3 | — |

### 2.3 模式（預設組合，可自訂）

| 模式 | 內容 |
|---|---|
| 一般 | 依上表的個別設定 |
| 訪客 | 不做任何身分辨識（臉、聲紋），不主動找人，不進入臥室 |
| 夜間（可排時段，例如 22:00–07:00） | 不主動走動、不出聲；喚醒聆聽可選擇保留；排程任務（例如叫起床）可設定為例外 |
| 完全隱私 | 鏡頭與麥克風都關；鴨子停在原地或充電座，只回應實體按鈕與手把 |

## 3. 誰可以改

- **收緊**（關掉某項、切到更嚴格的模式）：任何人隨時都可以，用語音（「鴨子，隱私模式」）、鴨子上的實體按鈕或設定頁都行。
- **放寬**（打開某項、切回較寬的模式）：**只能在 Mac 上的 Nous 設定頁操作**。不接受語音放寬，因為聲紋或人臉只是身分辨識，**不等於授權**（AIOS ADR-0001 的原則），也避免小孩或訪客用一句話打開鏡頭。
- 每次變更記錄時間、來源（設定頁／語音／按鈕）與變更項目，不記錄任何影像或聲音內容。
- 依 AIOS「功能便利性優先」的優先順序，設定頁本身不另外加密碼；若之後需要再加。

## 4. 在哪裡執行

規則要在**資料產生的地方**就擋下，而不是產生後才丟掉：

| 規則 | 執行位置 |
|---|---|
| 鏡頭、麥克風開關、房間是否可進入、可否出聲 | **鴨子（Pi 4 感知板）**：在開啟裝置或接受任務之前檢查 |
| 臉部比對、聲紋比對、家人是否可被找 | **Nous（Mac 核心）**：在比對或下達任務前檢查 |
| 模式與時段 | 兩邊都檢查（以同一份設定為準） |

- 設定存在 Nous 本機，以**版本化的設定文件**同步到鴨子（只含 ID，不含真實姓名）；schema 放在 `nous_duck/protocol/`（`privacy_policy.schema.json`，規劃中）。
- 鴨子拿不到最新版設定時（剛開機、斷線），使用**最後一次確認過的版本**；從來沒有拿到過，就用最嚴格的「完全隱私」。
- 違反規則的任務一律拒絕：工具結果 `refused`，原因代碼 `privacy_policy`（代碼清單待定），並說明是哪條規則，讓 Nous 能告訴使用者「哥哥房間現在不能進去」。
- **選配的實體開關**：鴨子身上加一個切斷鏡頭與麥克風 USB 電源的硬體開關，關掉時任何軟體都打不開。是否加裝待使用者決定（[ADR-0005](ADR-0005-compute-and-sensor-upgrade.md)）。

## 5. 預設值（2026-11-12 使用者同意）

| 項目 | 預設 |
|---|---|
| 鏡頭 | 只在導航、找人、對話、回充時開啟；待機與充電時關閉 |
| 常駐喚醒聆聽 | 開 |
| 臉部辨識 | 公共區域開；**臥室預設關** |
| 聲紋辨認 | 開 |
| 主動找人 | 開 |
| 臥室進入 | 只限指定任務（例如「叫起床」） |
| 夜間模式 | 22:00–07:00，排程的叫起床任務列為例外 |

以「叫哥哥起床」為例：任務是指定任務，可以進入 `brother_room`；臥室臉部辨識關閉，所以 `find_person` 改走到地圖上的 `brother_bedside`，用聲音叫人並聽回應。

## 6. 工具與介面

- `app.duck.status` 回報目前模式與主要開關狀態。
- 新增 `app.duck.privacy_tighten`（`reversible_write`）：只能**收緊**（切到更嚴格的模式或關掉某項）。**沒有給模型放寬的工具**。
- 設定頁屬於 AIOS 的介面，要依 AIOS 雙語規範提供繁體中文與英文；這是 AIOS repo 的批次。
