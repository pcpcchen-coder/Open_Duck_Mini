## 2. 過程與發現

1. **系統 Python 3.13 裝不了整套**（推論，沒有實際用 3.13 試裝）：上游鎖的 `onnxruntime==1.18.1`、`numpy==1.26.4`、`pygame==2.6.0` 沒有 3.13 版。改用 uv 另外裝 Python 3.11.18，不動系統 Python。
2. `uv pip install -e .`（Python 3.11）：上游鎖定的版本全部有 aarch64 wheel，**不用編譯**，1 分 18 秒裝完（第一次，含下載）。`rustypot==0.1.0`、`pypot`（`support-feetech-sts3215` 分支，當時 commit `f6d305e`）都裝得起來。
3. **`board` 載入失敗**：`RuntimeError: The platform library 'gpiod' was not found`。Blinka 10.2.0 在這個 kernel 上用 libgpiod。補裝 `gpiod==2.6.0` 後 `board.board_id` 是 `RASPBERRY_PI_4B`。上游 `setup.cfg` 沒有列 gpiod，`setup_runtime.sh` 另外裝。
4. 在 runtime 的 repo 根目錄執行 Python 時，同名資料夾 `mini_bdx_runtime/` 會蓋過已安裝的套件，`mini_bdx_runtime.*` 全部 `ModuleNotFoundError`。換到家目錄就正常。上游的腳本都在 `scripts/` 底下執行，不受影響；煙霧測試改在家目錄跑。
5. I2C 原本沒開。`raspi-config nonint do_i2c 0` 寫入 `dtparam=i2c_arm=on`，**重開機後**才有 `/dev/i2c-1`（`root:i2c`，660；`duck` 在 `i2c` 群組）。沒接 BNO055，`i2cdetect -y 1` 是空的。
6. 安裝完成後的套件版本用 `uv pip freeze` 存成 `runtime-constraints.txt`（53 個套件），腳本用 `-c` 套用，之後重裝會是同一組版本。

### 4.3 BNO055（2026-11-23）

模組是 **GY-BNO055**（紫藍色相容板，不是 Adafruit 原廠板），接法照上游：VIN→3V3（實體 1）、GND、SDA→GPIO 2（3）、SCL→GPIO 3（5）。

| 步驟 | 結果 |
|---|---|
| `i2cdetect -y 1` | 在 **0x29**。GY-BNO055 的 ADD 腳用 10 kΩ（板上標 `103`）拉到 3.3 V，預設 0x29；Adafruit 原廠板預設 0x28 |
| 直接用 `BNO055_I2C(i2c, address=0x29)` | 晶片 ID `0xA0`；靜止時加速度合力約 10.1 m/s²、陀螺儀三軸在 ±0.004 rad/s 以內；100 kHz 連讀沒有錯誤 |
| 上游 `raw_imu.py`（呼叫 `BNO055_I2C(i2c)`，函式庫預設 0x28） | `ValueError: No I2C device at address: 0x28` |
| **修正：ADD 接 GND**（杜邦線接 Pi 實體 6 號腳）。不改上游、不加軟體包裝 | 位址變成 **0x28** |
| 上游 `raw_imu.py`，原封不動執行 6 秒（`python -u`） | 115 筆、`[IMU]` 錯誤 0、traceback 0。前 3 筆是 0（背景執行緒還沒讀到），其餘 112 筆：加速度平均 (-1.17, -1.23, 8.68) m/s²、合力 8.85、標準差 ≤ 0.124；陀螺儀平均 ≤ 0.0007 rad/s、標準差 ≤ 0.0016 |

- 加速度合力 8.85 m/s²，比 9.81 低約 10%：`imu_calib_data.pkl not found`，**還沒校準**。上游有 `scripts/calibrate_imu.py`；`Imu` 在目前工作目錄找 `imu_calib_data.pkl`，所以要在 `scripts/` 底下產生。
- 模組還沒裝進機身，加速度方向只代表測試時擺放的姿勢；`imu_upside_down` 要裝好後核對。
- 溫度讀值是 -100 °C，明顯不對；上游步態不用溫度，沒有追查。
- 背面 SCL 與 SDA 焊點之間有一條細絲，已請使用者清掉；清掉前後 I2C 都正常。

## 5. 限制與下一步

- `check_motors.py` 只在低扭力下測過；`left_hip_yaw`、`neck_pitch` 讀值幾乎沒動（使用者目視有動一點）。零點偏移已校正並寫入，但還沒有在正常 kp 下讓鴨子擺出站姿（上游 `init_pos`）確認。IMU 還沒校準；沒有接足底開關（上游走路程式會讀 GPIO 22／27），沒有測天線 PWM。
- BNO055 在 Pi 上的 I2C 時脈伸展（clock stretching）問題：上游 README 也只寫「TODO set 400KHz ?」，現在是預設 100 kHz。接上 IMU 後如果讀值出錯，再調整。
- 上游 README 的 usb-serial latency udev 規則是給 FTDI（`ftdi_sio`）的；Waveshare 板是 `/dev/ttyACM*`（`cdc_acm`），不適用，沒設定。
- Xbox 手把：Pi 4 有藍牙（`hci0`，bluez 5.82，`bluetooth.service` 執行中），還沒有配對。
- `~/duck/servo-venv`（之前只裝 pypot 的設定站環境）留著沒刪；`runtime-venv` 也有 pypot，可以取代它。
